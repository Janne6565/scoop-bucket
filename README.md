# Janne's Scoop bucket

```powershell
scoop bucket add janne6565 https://github.com/Janne6565/scoop-bucket
```

## Apps

| name | description | install |
| --- | --- | --- |
| [wharf](https://github.com/Janne6565/wharf-tui) | Keyboard-driven terminal SSH client with a local-first encrypted vault | `scoop install janne6565/wharf` |

Manifests here are generated by [GoReleaser](https://goreleaser.com) on release
and overwritten on every version bump, so edits by hand do not survive.

On Windows, wharf's sessions run inside the process: detaching with `ctrl+\` keeps a
session running while wharf is open, but quitting closes it.
